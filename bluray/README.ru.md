# Интеграция Blu-ray в MPC-HC

[English](README.md)

Разработка начинается с официального MPC-HC **2.8.2**, с сохранением истории
и воспроизведения через LAV. Общие Blu-ray-наработки берутся из MPC-BE Blu-ray
по зафиксированному коммиту. Локальный прототип добавляет команду
**Файл → Открыть меню Blu-ray**, движок навигации libbluray и адаптер LAV.
DLL/JAR и компонентные проверки проходят. С madVR наблюдались HDMV-меню/начало
фильма и один цикл BD-J меню/фильм/возврат; широкие проверки дисков и точной
совместимости с madVR 210 ещё впереди.

Цель — Windows x64, libbluray 1.5.0 с сопровождаемыми патчами, внешние Java
и madVR 210 x64. Внутренняя libbluray в LAV — отдельная закреплённая зависимость;
новый модуль навигации не является её прямой заменой. Документация и сведения
об авторах исходного проекта сохранены на штатных местах.
