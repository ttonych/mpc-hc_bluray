# Интеграция Blu-ray в MPC-HC

[English](README.md)

Разработка начинается с официального MPC-HC **2.8.2**, с сохранением истории
и воспроизведения через LAV. Общие Blu-ray-наработки берутся из MPC-BE Blu-ray
по зафиксированному коммиту. Штатное открытие диска/папки/ISO учитывает выбор
меню или основного фильма; отдельной команды открытия меню нет. Добавлены
движок навигации libbluray, адаптер LAV и штатные EN/RU-настройки. Сборки DLL/JAR
и компонентные проверки проходят. Наблюдались HDMV и ограниченный цикл BD-J;
точная версия madVR 210 подтверждена. Основной режим — D3D11 fullscreen windowed.
Широкая матрица дисков и подтверждение именно облачного ZIP ещё впереди.

Цель — Windows x64, libbluray 1.5.0 с сопровождаемыми патчами, внешние Java
и madVR 210 x64. Внутренняя libbluray в LAV — отдельная закреплённая зависимость;
новый модуль навигации не является её прямой заменой. Документация и сведения
об авторах исходного проекта сохранены на штатных местах.
