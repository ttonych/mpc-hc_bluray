# Изменения форка

[English](CHANGELOG.md) · [Нумерация и выпуски](docs/RELEASING.ru.md)

Здесь записаны дополнения MPC-HC Blu-ray к официальному плееру.
Изменения исходного плеера описаны в [официальном выпуске MPC-HC 2.8.2](https://github.com/clsid2/mpc-hc/releases/tag/2.8.2).
При публикации записи получают отдельный раздел с версией и датой выпуска.

## Не выпущено

Планируемый первый выпуск: **2.8.2-bluray.1** на основе официального **MPC-HC 2.8.2**.
Release ещё не опубликован. Точные сведения о кандидатах и результатах проверки
хранятся отдельно в [Validation](docs/VALIDATION.ru.md).

### Добавлено

- Обязательный portable-профиль, мастер импорта EN/RU из реестра или INI,
  копирование HLSL с подпапками без изменения источника. История/плейлисты
  и сохранения BD-J исключены; невозможность записи не включает чужой профиль.
- HTML-руководства EN/RU в ZIP со встроенным оформлением и проверкой ссылок.

- Экспериментальная навигация HDMV/BD-J, клавиатура и предусмотренная диском мышь,
  графика меню через madVR и отдельный граф звука меню.
- Штатные команды главного/всплывающего меню (Alt+T/Alt+R), названия дисков
  и отметки глав, скрывающиеся в меню и возвращающиеся при просмотре фильма.
- Обычное открытие диска/папки с выбором основного фильма или меню. Мастер первого запуска
  выбирает меню; временная отдельная команда открытия меню удалена.
- Открытие ISO через Windows только для чтения, включая перетаскивание.
  Собственные подключения сохраняются при смене графа и освобождаются при закрытии;
  внешние подключения сохраняются, ошибки сообщаются.
- Штатные русские/английские настройки Blu-ray: регион/языки, Java, отдельные
  папки сохранений/кеша BD-J, проверяемое применение и отмена неприменённых правок.
- Окно совместимости с 14 параметрами libbluray, пояснениями, наборами значений
  и сбросом настроек только в черновике.
- Каталог данных дисков: поиск, свои названия, доступ к папкам и сброс отдельного
  диска с сохранением прежних файлов сохранений/кеша.
- Проверка разрядности JVM и ограниченная по времени, отменяемая диагностика
  запуска Java в отдельном процессе.

- Версия форка в «О программе», ProductVersion EXE и заголовке пустого окна
  из единого заголовка для плеера/упаковщика; рядом указана ревизия исходников.
- Проверка опубликованных GitHub-выпусков форка, включая prerelease, с числовым
  сравнением, штатным ответом при отсутствии выпусков и переходом на страницу Release.

### Исправлено

- Расчёт ревизии основы игнорирует теги форка и других версий; упаковка отклоняет
  устаревшую ProductVersion EXE и несовпадающую версию русских ресурсов.
- Доступность и маршрутизация штатных команд меню Blu-ray с учётом запретов диска.
- Временные метки LAV сохраняют авторские паузы между редкими кадрами навигации;
  повторы отдельных MPEG-2 кадров и обработка конца последовательности устраняют
  наблюдавшийся чёрный экран начального предупреждения. Обычное воспроизведение
  сохраняет прежнюю компенсацию разрывов времени.
- Штатная полноэкранная панель доступна, когда Blu-ray обрабатывает движение мыши.
- Явные 32-битные маски совместимости, включая 0xFFFFFFFF, сохраняются после
  перезапуска и не смешиваются с автоматическими значениями при смене языка.
- Запрос состояния процесса меняет только debug-байт PEB, проверяет результаты
  и буферы, обрабатывает полное значение debug port.
- Повреждённая русская навигация английского README; быстрые проверки теперь
  отклоняют неверный UTF-8 и отсутствующие/повреждённые ссылки на парный перевод.

### Компоненты, сборка и документация

- Сохранены история официального MPC-HC 2.8.2 и ревизии LAV.
- Интегрированы native/Java-патчи libbluray 1.5.0 для мыши страниц меню, меток
  перемотки и HAVi toggle; записаны хеши, происхождение и компонентные проверки.
- Адаптер PID/PlayItem/timestamps/статичных кадров LAV сопровождается отдельно
  от внутренней libbluray LAV. Для текущей сборки и проверок закреплена
  Temurin 21.0.12.1+1 x64.
- Добавлены скрипты сборки x64/EN/RU, регрессии настоящего JAR и нативного кода,
  проверки публикации/истории/авторов, быстрые PR-проверки и ручная облачная сборка.
- Пакет собирается по явному списку runtime/лицензий/документов с чистым portable-INI.
  Java и madVR остаются внешними; основной режим madVR — D3D11 fullscreen windowed.
- Расширены парные руководства по запуску, Java, сохранениям, диагностике, участию
  и выпуску; закреплена схема исходной версии и номера выпуска форка.

### Известные ограничения

- Версия экспериментальная. Текущий облачный кандидат прошёл ограниченные
  HDMV/BD-J-проверки; расширенное покрытие дисков, Java/сохранений и меню с мышью
  не завершено.
- MSVC-конфигурация LAV отличается от штатной GCC; полное равенство кодеков/звука,
  точность HDR, MVC/стереовывод и DVD ISO не подтверждены.
- В [Validation](docs/VALIDATION.ru.md) разделены компонентные тесты, локальное
  воспроизведение, сообщения пользователя и проверки точного облачного ZIP.
