# Изменения форка

[English](CHANGELOG.md)

## Не выпущено — локальная разработка

- Основа — официальный MPC-HC 2.8.2 с сохранением истории и ревизий LAV.
- Перенесено исправление запроса состояния процесса: запись только debug-байта
  PEB, проверки результатов/буферов и обработка полного значения debug port.
- Перенесены native/Java-патчи libbluray 1.5.0, манифесты и компонентные регрессии;
  добавлены скрипты сборки/проверки x64, происхождение и двуязычные документы.
- Добавлены экспериментальная Blu-ray-навигация, клавиатура/мышь,
  графика madVR и отдельный граф звука меню.
- Добавлены сопровождаемые патчи LAV для выбора PID и границ чтения PlayItem;
  внутренняя библиотека LAV отделена от навигационной libbluray 1.5.0.
- Собраны свежие DLL/JAR, закреплена Java 21.0.12.1+1 x64; проверены HAVi,
  графика, координаты, часы и программное декодирование LAV через Null Renderer.
- Первое HDMV-меню наблюдалось с madVR в локальном русском portable-плеере.
  Также пройден один цикл BD-J меню/начало фильма/возврат с закреплённой Java.
  Широкая проверка дисков и мышь BD-J остаются открытыми; точный madVR 210 подтверждён ниже.
  MSVC-конфигурация LAV отличается от штатной GCC; релизного пакета пока нет.
- Подключены штатные команды навигации и доступность пунктов меню к Blu-ray:
  Alt+T/верхнее меню, Alt+R/всплывающее, направления, активация и выход; ограничения диска сохраняются.
- Добавлены название диска и скрытие глав на обычной/OSD-шкале при активном меню.
- В режиме Blu-ray-навигации LAV сохраняет авторские паузы между редкими кадрами;
  обычное воспроизведение сохраняет прежнюю компенсацию разрывов времени.
- В LAV адаптированы повторы отдельных статичных MPEG-2 кадров и обработка конца
  последовательности из MPC-BE; начальное предупреждение теперь видно с madVR.
- Обычное открытие Blu-ray учитывает выбор меню/фильма; по умолчанию сохраняется
  основной фильм.
- Добавлена штатная EN/RU-страница Blu-ray: регион/языки, поиск/каталог Java,
  отдельные папки сохранений/кеша BD-J, проверка применения и отмена правок.
- Удалён временный отдельный пункт открытия меню Blu-ray; штатное «Открыть DVD/BD»
  учитывает выбранный режим. Добавлено окно совместимости с 14 параметрами,
  EN/RU-пояснениями, проверкой значений и сбросом настроек только в черновике.

- Сохранены явные 32-битные маски совместимости, включая 0xFFFFFFFF, после
  перезапуска; перевод подписи не смешивает явный выбор со значением по умолчанию.

- Добавлен EN/RU-каталог данных дисков: поиск, свои названия, старые общие папки,
  доступ к папкам и сброс диска с сохранением прежних файлов.
- Проверяется разрядность JVM перед применением Java; добавлена ограниченная
  по времени и отменяемая проверка java -version вне плеера.
- Сохранено появление штатной панели полного экрана при обработке движения мыши меню Blu-ray.
- Открытие перетащенных ISO через виртуальный привод Windows только для чтения
  учитывает выбор меню/фильма Blu-ray. Подключение сохраняется при смене графа
  и освобождается при закрытии; внешние подключения сохраняются, ошибки сообщаются.

- Проверены смена/отключение ISO, точный madVR 210 и обычные H.264/HEVC10/AV1/
  MPEG-2. Основной режим — D3D11 fullscreen windowed.
- Добавлены проверки файлов/истории/авторов, двуязычные инструкции и результаты,
  быстрые PR-проверки, ручная облачная сборка и чистый ZIP по явному списку.
