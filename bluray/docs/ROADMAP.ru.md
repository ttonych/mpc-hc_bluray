# План

[English](ROADMAP.md)

## Что уже выполнено

- Основа MPC-HC 2.8.2 с историей и закреплёнными зависимостями; x64-плеер,
  EN/RU-ресурсы, libbluray 1.5.0 DLL/JAR и адаптер LAV собраны.
- Проходят компонентные проверки графики, часов, координат, меню, HAVi на
  настоящем JAR, PID/PlayItem, навигационных команд и LAV с Null Renderer.
- Наблюдались HDMV-меню/начало фильма и BD-J меню/фильм/возврат; пользователь
  отдельно предварительно подтвердил клавиатуру и мышь на одном HDMV-диске.
- Подключены Alt+T/Alt+R и штатные команды меню. Добавлены название диска и
  скрытие глав при активном меню, с восстановлением для фильма.
- LAV сохраняет авторские паузы и повторяет отдельные MPEG-2 заставки для madVR.
  Начальное предупреждение визуально подтверждено; проходят регрессии парсера,
  software/DXVA2-декодирование и проверка числа кадров обычного MPEG-2.
  Скрытие/возврат глав в цикле меню/фильм/меню проверены визуально.
- Обычное открытие Blu-ray учитывает выбор фильма/меню. Штатная EN/RU-страница
  задаёт регион/языки, Java и хранилище BD-J; проходят регрессии рабочих методов,
  обе сборки и локальные проверки применения/отмены/перезапуска. Оба режима
  открытия и отдельный вызов меню визуально проверены с madVR.

- Каталог дисков и явная диагностика Java реализованы. Проходят искусственные
  тесты хранилища и дочернего процесса; локально проверены EN/RU GUI, запуск Java
  и отклонение x86 JVM в x64-плеере. Прежние сохранения остаются на месте.

- На одном BD-J-диске проверены сброс/повторное открытие на копии каталога с
  искусственным контрольным файлом, popup/верхнее меню, выбор звука, видимые
  английские субтитры, главы вперёд/назад и перемотка. Главы штатной панели полного
  экрана следуют переходам меню/фильм/возврат. Это проверки агента на одном диске.
- Исправлено появление панели полного экрана при перехвате движения мыши меню
  Blu-ray; пройдены GUI-проверка до/после и smoke обычного MPEG-2.

- Открытие ISO реализовано: проходят native/маршрутные проверки, наблюдались
  меню, фильм, закрытие и повтор. Пользователь подтвердил меню через drag-and-drop.

- Проходят смена ISO/названия/отключение и переход к обычным файлам. Выбор
  основного фильма подтверждён состоянием нативного окна; ограничение снимка
  записано в [проверках](VALIDATION.ru.md).
- Точный madVR 210 подтверждён хешами официального архива и загруженного модуля.
  Основной режим — D3D11 fullscreen windowed. Дополнительный временный тест
  exclusive-шкалы также прошёл; исходные глобальные настройки восстановлены.
- Синтетические H.264, HEVC Main10, AV1 и MPEG-2 показываются с madVR и полностью
  декодируются изменённым LAV. Компонентные проверки и тест настоящего JAR проходят.
- Подготовлены и проверены локально сканер публикации, проверка метаданных автора,
  парных документов/ресурсов, ручной облачный workflow и упаковка по явному списку.
- Первичный перенос принят через [PR №1](https://github.com/ttonych/mpc-hc_bluray/pull/1).
  `main` требует PR и успешный `source-check` GitHub Actions, включая администраторов;
  force-push и удаление запрещены. Быстрые проверки CI проходят.
- Первая ручная облачная сборка прошла; её точный ZIP проверен на целостность,
  HDMV, обычный файл, fullscreen windowed и EN/RU в ограниченном объёме. BD-J
  на этом ZIP ещё не подтверждён: Windows не подключает текущий тестовый образ.
  Подробности записаны в [проверках](VALIDATION.ru.md).

- Реализованы версия форка и проверка его выпусков. Пройдены локальные сборки
  x64/RU, тесты версии/тегов/API и настоящие EN/RU-окна «О программе»/обновлений.
  В прежнем облачном ZIP этих изменений нет.

## Ближайшие незакрытые задачи

1. Адаптировать обязательную изоляцию portable-профиля и мастер первого импорта;
   добавить offline-HTML руководств. См. [сравнение возможностей](PARITY.ru.md).

2. Расширенная матрица BD-J: меню с мышью, Java/сохранения, другие диски, звук/
   статика меню, сочетания языков и дополнительные пути декодеров.
3. Проверить именно облачный ZIP по оставшейся матрице выпуска с чистым профилем;
   локальные результаты не подтверждают облачный пакет. См. [проверки](VALIDATION.ru.md).

## Возможности донора для дальнейшей оценки

- Обязательный portable-профиль и импорт настроек при первом запуске с сохранением
  источника и изоляцией истории/данных BD-J. Сейчас изоляция зависит от наличия
  комплектного INI рядом с EXE.
- Offline-HTML руководств и последующие улучшения выбора Java. Сейчас документы
  пакета — Markdown; незакоммиченные правки донора не являются основой переноса.

Это явные пробелы, а не заявление о равенстве возможностей или автоматическое
поручение перенести все будущие функции донора. Используйте фиксированные коммиты
и записывайте результат отбора.

Версия остаётся экспериментальной. Полная совместимость, точность HDR, DVD ISO
и стереовывод MVC не подтверждены. Новые версии не заменяют основу автоматически.

Отдельная команда меню, использованная в начальных проверках, удалена.
Для настроек совместимости пройдены проверки нативного EN/RU-окна, применения,
отмены, сброса и перезапуска, включая полные 32-битные маски. Пользователь
подтвердил нормальный Sony-ролик без RDP; агент также видел его при открытии и
повторном открытии. Прежний непостоянный сбой сейчас не воспроизводится; причина
и исправление не заявляются. Пользователь подтвердил: это конкретное авторское
меню мышь не поддерживает; отсутствие активации кликом ожидаемо, это не дефект HC.
Общая проверка мыши BD-J остаётся для меню с известной поддержкой. Штатные панели полного экрана и шкала рендерера проверяются отдельно.
