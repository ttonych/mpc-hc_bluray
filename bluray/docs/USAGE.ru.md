# Использование MPC-HC Blu-ray

[English](USAGE.md) · [Проект](../../README.ru.md)

Распакуйте ZIP кандидата в новую папку с правом записи. Оставьте комплектный INI
рядом с EXE: он выбирает portable-настройки. Не распаковывайте поверх установленного
плеера и не копируйте личный профиль в пакет для распространения.

1. Отдельно установите madVR 210 x64 и выберите madVR в Настройки > Воспроизведение > Вывод.
   Используйте D3D11 fullscreen windowed; exclusive не требуется.
2. Для BD-J установите Java x64. Проверенная версия — Temurin 21.0.12.1+1.
   Выберите её папку на странице Blu-ray и при необходимости нажмите «Проверить Java».
3. На странице Blu-ray выберите меню или основной фильм. Открывайте диск/папку
   через «Открыть DVD/BD» либо перетаскивайте ISO в окно. Отдельной команды открытия
   меню не требуется. Для ISO нужны штатное подключение Windows и читаемый образ.
4. Управляйте стрелками и Enter. Alt+T вызывает главное меню, Alt+R — всплывающее/
   корневое. Работа мыши и запреты отдельных действий зависят от самого диска.

Сохранения и кеш по умолчанию находятся в `bdj-data` рядом с плеером. Диалог
«Данные дисков» показывает распознанные диски, позволяет задать псевдоним и
подготовить пустые сохранения/кеш для следующего открытия. Сброс сохраняет прежние
файлы и не сбрасывает другие диски. Не распространяйте свой INI и сохранения.

Java и madVR не входят в комплект. Их системные настройки могут быть общими для
разных плееров даже при portable-профиле MPC-HC. Ошибка открытия меню отображается;
плеер не подменяет неудачное открытие меню запуском основного фильма.
Проект не предоставляет ключи дисков или компоненты расшифровки.

Перед заменой привычного плеера прочтите [проверки и ограничения](VALIDATION.ru.md).
Воспроизведение обычных файлов сохраняется.
