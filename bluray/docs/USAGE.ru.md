# Использование MPC-HC Blu-ray

[English](USAGE.md) · [Проект](../../README.ru.md)

## Требования и первый запуск

Нужны Windows x64 и читаемое содержимое Blu-ray. Проект не предоставляет ключи
или компоненты расшифровки. Java и madVR устанавливаются отдельно и не входят
в ZIP плеера. Обычные медиафайлы по-прежнему открываются штатными путями MPC-HC.

Скачайте кандидат по ссылке на [странице проекта](../../README.ru.md). Если GitHub
упаковал артефакт в дополнительный архив, извлеките внутренний ZIP плеера в новую
папку с правом записи. Оставьте `mpc-hc64.ini` рядом с `mpc-hc64.exe`: его наличие
выбирает portable-настройки. Не распаковывайте поверх установленного плеера.
Запускайте этот EXE напрямую, чтобы ассоциации файлов не открыли другую установку.

Компонентам LAV, собранным через MSVC, нужны библиотеки Microsoft Visual C++ v14
x64 не старее сборочного инструментария. Если их нет, используйте
[официальный установщик Microsoft Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist).

Выберите **Настройки → Воспроизведение → Вывод → madVR**, используя отдельную
установку **madVR 210 x64**. Основная проверяемая полноэкранная конфигурация —
**D3D11 fullscreen windowed**. Форк не включает exclusive и не настраивает madVR
глобально. Настройки madVR и внешних фильтров могут быть общими у разных плееров.

## Java для BD-J

Меню HDMV не требуют Java; меню BD-J требуют. Проверенная установка — **Temurin
JDK 21.0.12.1+1 x64**. Для воспроизведения нужна полноценная Java с поддержкой
desktop/AWT; для сборки JAR дополнительно нужен JDK. Более новая основная версия
Java не считается автоматически совместимой заменой.

В **Настройки → Воспроизведение → Blu-ray** выберите папку установки Java,
а не `java.exe` или `jvm.dll`. Кнопка **«Проверить Java»** проверяет выбранную
установку и запускает её launcher в отдельном процессе. Успех подтверждает запуск
Java, но не совместимость с конкретным диском. Плееру x64 нужна Java x64;
неверную явно выбранную установку применить нельзя.

Пустое поле разрешает автоматический поиск при открытии диска. Для повторяемых
проверок выбирайте проверенную версию явно. Нажмите **«Применить»** или **OK**
и заново откройте диск после смены Java. Используйте комплектные `bluray-4.dll`
и оба JAR libbluray вместе; не смешивайте runtime-файлы разных сборок.
Точные версии записаны в [sources.json](../sources.json).

## Открытие диска или ISO

1. На странице Blu-ray выберите **«Меню диска»** или **«Основной фильм»**.
   В чистом профиле по умолчанию выбран фильм. Примените выбор и откройте диск заново.
2. Используйте **«Открыть DVD/BD»** для корня диска или папки `BDMV`. Точки входа
   `index.bdmv` и `MovieObject.bdmv` также следуют выбранному режиму открытия.
3. Откройте или перетащите читаемый файл `.iso` в плеер. Требуется штатное
   подключение образов Windows. Плеер подключает образ только для чтения, сохраняет
   своё подключение при смене плейлистов и освобождает после закрытия воспроизведения.
   Внешнее подключение используется без принудительного отключения при закрытии.
4. Отдельный плейлист `.mpls` или клип `.m2ts` открывается как обычный файл;
   это не запрос полноценной навигации по диску.

Отдельной команды «Открыть меню Blu-ray» нет. Ошибка меню отображается,
а не заменяется молчаливым запуском фильма. Для неподдерживаемого образа или сбоя
подключения ожидается ошибка. Другие форматы образов и сторонние средства
подключения в комплект не входят.

## Управление

| Действие | Управление по умолчанию |
| --- | --- |
| Перемещение по меню | Стрелки |
| Активация выбранного пункта | Enter |
| Вызов главного меню | Alt+T или Home |
| Вызов всплывающего/корневого меню | Alt+R или клавиша Apps |
| Выбор мышью | Движение/щелчок, если это предусмотрено диском |
| Смена главы или перемотка фильма | Штатные команды глав MPC-HC и шкала времени |

Меню плеера и контекстное меню используют те же команды навигации. Диск может
запретить действие или поддерживать только клавиатуру. Неактивный пункт или
отсутствие реакции на мышь сами по себе не доказывают ошибку плеера.
Изменённые назначения клавиш смотрите в **Настройки → Проигрыватель → Клавиши**.

Отметки глав скрываются в меню диска и возвращаются при просмотре фильма.
Заголовок окна берёт название из метаданных, а при их отсутствии — из имени
тома или папки. Полноэкранная панель плеера должна появляться у нижнего края.

## Языки, регион и совместимость

Страница Blu-ray задаёт регион, страну и предпочтительные языки меню, звука
и субтитров. Это предпочтения: нужный язык может отсутствовать, а диск может
применять собственный выбор. Поля страны и языков также принимают двухбуквенные
коды стран и трёхбуквенные коды языков ISO. Изменения действуют со следующего
открытия после **«Применить»** или **OK**.

В **«Совместимость…»** находятся параметры libbluray: возраст, профиль плеера,
запреты навигации и заявленные возможности звука/видео. Оставляйте автоматические
значения, если не исследуете воспроизводимую проблему диска. Эти параметры сообщают
диску возможности плеера; они не устанавливают декодеры и не подтверждают HDR/MVC.
**OK** в дочернем диалоге подготавливает изменения, а **«Применить»/OK** в основном
окне настроек сохраняет их. **«Отмена»** отбрасывает неприменённые изменения.
Возврат параметров по умолчанию здесь не сбрасывает сохранения дисков.

## Сохранения дисков

По умолчанию сохранения и кеш находятся в `bdj-data` рядом с плеером. На странице
Blu-ray можно выбрать отдельные папки. Изменение пути не переносит и не удаляет
существующие файлы; обеспечьте право записи и затем заново откройте диск.

**«Данные дисков…»** показывает распознанные диски, псевдонимы и даты последнего
открытия, поддерживает поиск, обновление списка и открытие папок. Диалог использует
уже применённые пути. Псевдоним меняет отображаемое имя, а не физический каталог.

Подтверждённый **«Сброс»** выбирает пустые папки сохранений/кеша для следующего
открытия этого диска. Прежние файлы остаются, активный сеанс сохраняет свои пути,
а данные остальных распознанных дисков не меняются. Общую группу старых данных
нельзя сбросить как отдельный распознанный диск. Сброс и смена псевдонима действуют
сразу; отмена окна настроек не откатывает их. Перед экспериментами делайте копии
ценных сохранений и не публикуйте каталог дисков или файлы сохранений.

## Профили и обновления

Мастер импорта профиля и обязательный portable-режим MPC-BE Blu-ray ещё не
перенесены. Сохраняйте комплектный INI: без него штатное поведение MPC-HC может
использовать профиль установленного плеера в реестре. Для проверки берите новую
папку и комплектный пустой профиль, затем меняйте только необходимые настройки.

Текущие исходники показывают **2.8.2-bluray.1** в «О программе», заголовке пустого
окна и ProductVersion EXE; «О программе» также содержит commit исходников. См.
[схему версий](RELEASING.ru.md). Справка → Проверить обновления обращается к
опубликованным выпускам **ttonych/mpc-hc_bluray** на GitHub, включая prerelease.
Числовые части основы/выпуска сравниваются по порядку; плеер предлагает страницу
выбранного выпуска, без установки или замены файлов. Автоматическая проверка,
если включена, использует тот же источник.

Отсутствие опубликованных выпусков форка — штатный результат, отличный от ошибки
сети/API. Отдельные Git-теги, черновики Release и выпуски официального MPC-HC
не предлагаются как обновления форка. Старый облачный ZIP из Actions 35781918063
создан до этой реализации и сохраняет унаследованный updater; в этом кандидате
откажитесь от автоматической проверки.

Перед переходом на новый кандидат закройте старый плеер, распакуйте новую сборку
отдельно и сохраните прежнюю папку для возврата. Прочтите [историю изменений](../CHANGELOG.ru.md).
Начните с чистого профиля; при последующем переносе настроек или сохранений
работайте с резервными копиями и проверяйте пути Java и хранилищ. Не направляйте
экспериментальный сброс на единственную копию реальных сохранений. Не распространяйте
использованный INI или данные BD-J.

## Диагностика и обратная связь

| Симптом | Что проверить |
| --- | --- |
| Сразу начинается фильм | Выберите меню диска, примените и заново откройте весь диск, а не отдельный клип/плейлист. |
| HDMV работает, BD-J — нет | Выберите проверенную Java x64, нажмите «Проверить Java», проверьте комплектность DLL/JAR и заново откройте диск. |
| Чёрный экран или нет графики меню | Проверьте madVR и его режим; сравните на локальном рабочем столе, поскольку результат по RDP не равнозначен. Укажите, сохраняются ли звук и выбор пунктов. |
| Мышь не действует | Попробуйте стрелки/Enter и укажите, поддерживает ли конкретное меню мышь в плеере для сравнения. |
| ISO зависает на «Открытие…» или даёт ошибку | Закройте воспроизведение и проверьте подключение и чтение этого образа средствами Windows. Сообщите ошибку и тип образа; не маскируйте ошибки чтения/CRC. |
| Настройки не действуют | Примените их и откройте диск заново; проверьте папку EXE/INI, наличие языка и запреты диска. |
| При запуске не хватает runtime | Проверьте библиотеки Visual C++ x64 и полноту распаковки архива. |

О воспроизводимой проблеме сообщайте в [issues этого форка](https://github.com/ttonych/mpc-hc_bluray/issues).
Укажите commit/версию кандидата, Windows, режим рендерера, Java для BD-J, способ
открытия, издание/регион диска, точные шаги и ожидаемое/фактическое поведение.
Разделяйте результаты клавиатуры и мыши, меню и фильма. Сравнение с MPC-BE полезно
с его точной версией, но не подтверждает работу MPC-HC. Перед отправкой журналов
или снимков проверьте личные пути и данные; не прикладывайте содержимое дисков,
сохранения, личные профили или дампы памяти.

В [проверках и ограничениях](VALIDATION.ru.md) перечислены проверенные сценарии
и пробелы. Компиляция или запуск одного меню не означает готовность к выпуску.
