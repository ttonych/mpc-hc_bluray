# Сравнение возможностей MPC-BE / MPC-HC Blu-ray

[English](PARITY.md) · [Переносы](PORTING.ru.md) · [Проверки](VALIDATION.ru.md)

Дата сравнения: **2026-09-23**. Сравниваются дополнения к официальным плеерам,
а не все возможности исходных MPC-BE и MPC-HC.

- Донор: [MPC-BE Blu-ray на 270cfdd](https://github.com/ttonych/mpc-be_bluray/tree/270cfdd4369224dd4108d0b1d1b8a4ab7b8fc56d),
  основа MPC-BE 1.9.1. База переноса — только закоммиченный код.
- HC: облачный кандидат `c4d242333bed` на MPC-HC 2.8.2, включая обозначение
  форка, проверку выпусков, обязательный portable-импорт и offline-HTML.
  Точный пакет и результаты записаны в [проверках](VALIDATION.ru.md).
- Выпуск донора `1.9.1-bluray.1` собран на `c671077`; сравниваемый коммит также
  содержит последующие исправления времени жизни ISO и возврата из BD-J.
  Возможности исходников и выпущенного ZIP нужно различать в обоих проектах.

## Добавленные возможности

«Есть» означает наличие реализации. Это не доказывает одинаковую совместимость
со всеми дисками или готовность скачиваемого пакета.

| Дополнение | MPC-BE Blu-ray | MPC-HC Blu-ray | Оценка |
| --- | --- | --- | --- |
| Навигация HDMV/BD-J через libbluray 1.5.0 | Есть | Адаптирована к HC/LAV | Общие патчи библиотеки побайтово одинаковы |
| Меню madVR: RLE/ARGB, координаты, часы, фон и цвет | Есть | Есть | Общие вспомогательные заголовки сохранены; интеграция рендерера своя |
| Клавиатура, авторская мышь, главное/popup-меню, дорожки и главы | Есть | Есть | Мышь зависит от диска; HC нужна положительная проверка мыши BD-J |
| Название диска и главы с учётом меню/фильма | Есть | Есть | Адаптация заголовка/шкалы HC проверена регрессиями и локально в GUI |
| Звук меню и статичные MPEG-2 кадры | Есть | Есть | В HC собственный граф звука и сопровождаемый патч времени/статики LAV |
| Выбор фильма/меню и штатное открытие ISO | Есть | Есть | HC сохраняет свои подключения при смене графа и не освобождает внешние |
| Регион/страна/языки, совместимость и хранилище BD-J | Есть | Есть | Штатные окна устроены по-разному; пропущенных параметров не обнаружено |
| Каталог дисков, псевдонимы, сброс с сохранением старых данных | Есть | Есть | Общие алгоритмы каталога/хранилища, собственные диалоги HC |
| Явная проверка разрядности Java и отменяемая диагностика запуска | В этой ревизии ограничена проверкой файлов | Реализована | В HC диагностика шире; дальнейшая Java-работа донора вне базы сравнения |
| Версия форка и проверка собственных опубликованных выпусков | Есть | Есть в текущем кандидате | HC обращается к своим выпускам, включая prerelease |
| Импорт при первом запуске и обязательный portable-профиль с правом записи | Есть | Адаптировано | Форматы HC, сохранность источника, проверки мастера EN/RU |
| Offline-HTML руководств внутри ZIP | Есть | Адаптировано | Проверка локальных страниц/якорей, ссылки на точный commit |

Общие патчи `mouse-page-v1`, `playmark-seek-v1`, `bdj-toggle-v1` и вспомогательный
код графики, часов, каталога, хранилища и звука меню записаны в
[imports.json](../imports.json). Граф/декодеры HC адаптированы, а не заменены
фильтрами BE. Одинаковое название функции само по себе не доказывает идентичность кода.

## Границы сравнения и оставшаяся работа

1. Расширить матрицу дисков HC. Прежний ZIP `19dfdc8b307f` прошёл проверки
   HDMV/BD-J, включая дорожки, главы и авторское продолжение просмотра BD-J.
   Прежний пробел облачной BD-J-проверки закрыт для этого кандидата через внешне
   подключённый привод. По уточнению пользователя, особенность штатного подключения
   связана с хранением ISO и исключена из дефектов плеера. Опубликованного Release HC
   пока нет. Мышь BD-J и широкая матрица Java/сохранений остаются открытыми.
2. Поведение при ошибках чтения проверено на реальном HC/LAV.
   [Исправление e857bdc донора](https://github.com/ttonych/mpc-be_bluray/commit/e857bdcef19a4a8975cc2fb2fb4709b32ee7b1de)
   ограничивает `CMultiFiles` одним повторным открытием/чтением с той же позиции,
   возвращает постоянную ошибку и исключает обращение к отсутствующей таблице
   временных смещений у отдельного M2TS. Тесты с искусственным отказом проверяют
   успешный повтор, ровно две попытки при постоянной ошибке и смещения плейлиста.
   HC сохраняет LAV/libbluray и адаптирует ограниченный повтор и сообщение об
   отказе в `hc-menu-bridge-v4`. Тесты выявили потерю пакетов при разовом отказе
   и ложный успешный конец фильма при постоянной ошибке в v3. Локальный v4
   проходит точное сравнение данных/времени, повтор на границе клипов, постоянную
   ошибку и перезапуск того же графа. Отдельный M2TS и сообщение/повторное открытие
   HC EN/RU с madVR 210 тоже проверены локально. Прежний ZIP содержит v3.
   Новый ZIP с v4 проходит отказы чтения, но визуальная проверка HDMV/BD-J
   и madVR ещё требует локального сеанса.
   Долгие таймауты ОС/сети и повреждённые носители не охвачены
   [этими проверками](VALIDATION.ru.md).

Бесшовные переходы плейлистов, BD-Live/PiP, авторские звуки кнопок и полное
управление расположением видео/синхронизацией паузы из Java не заявляются как
подтверждённое равенство возможностей. Сравнение и воспроизведение меню не
доказывают точность HDR и полный MVC/стереовывод. См. ограничения обоих проектов
и [план HC](ROADMAP.ru.md).

Эксперименты донора с выбором Java на момент сравнения не закоммичены и исключены.
Оценивать их нужно по фиксированному проверенному коммиту вместе с тестами.
В сравниваемом закоммиченном наборе пропущенных основных патчей библиотеки не
найдено; это ограниченная проверка исходников, а не заявление о полном равенстве
воспроизведения.
