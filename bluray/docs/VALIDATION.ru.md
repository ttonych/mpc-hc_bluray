По сообщению пользователя, проверенное авторское меню A Knight's Tale не
поддерживает мышь. Оно не подходит для положительного подтверждения мыши в BD-J.
Собственная шкала exclusive madVR не подтверждает отрисовку глав на нативной/
OSD-шкале MPC-HC: это отдельные пути.

Эталон рендерера: [официальный архив beta 210](https://madshi.net/madVRhdrMeasure210.zip).
SHA-256 архива:
`2d714db856b8012a6676d809c59689f2f8752d2c2afeb7cb3f42137cf818276a`.
SHA-256 загруженного `madVR64.ax` и файла внутри архива:
`c4093c6dfc2f549fab5f08bc940587c6fcb35195f8a589b1130d58bf5e4460e4`.
Бинарные файлы рендерера, снимки экрана и содержимое дисков в репозиторий не входят.

Перед выпуском повторите HDMV/BD-J, чистый portable-профиль, EN/RU, меню/фильм/
возврат, дорожки, главы, Warning/статику и обычные файлы именно на облачном ZIP.
Запишите commit исходников и SHA-256. Расширенные проверки мыши/жизненного цикла
BD-J, воспроизведение DVD ISO, точность HDR и MVC/стереовывод ещё не завершены.

## Первый облачный кандидат

[Ручная сборка 35781918063](https://github.com/ttonych/mpc-hc_bluray/actions/runs/35781918063)
успешно завершена 22.09.2026 UTC на коммите
`8183fe6579c113bebe1ab4b2818807c41400de16`. На облачном runner прошли сборки
плеера, своего LAV, RU-ресурсов, компонентные проверки и HAVi на настоящем JAR.

Артефакт: `mpc-hc-bluray-candidate-x64`.
ZIP: `mpc-hc_bluray-2.8.2-bluray.1-8183fe6579c1-x64.zip`.
SHA-256: `dee5f9188d227b4dacfe2b20ae09a2f7ccf5ef29e211fe67b1c6f8ca5ee7eefc`.
Скачанный ZIP прошёл проверку CRC, точного состава, хешей всех 76 файлов и чистого
профиля. ZIP и исходная распаковка сохранены; запускалась отдельная копия с новым
portable-профилем и внешними madVR/Java.

| Проверка облачного ZIP | Результат агента |
| --- | --- |
| Загруженные компоненты | LAV и навигационная DLL загружены из облачного пакета; хеш madVR совпал с beta 210 выше. |
| HDMV | Наблюдались меню Baby Boom, Enter → фильм и возврат Alt+T. |
| Полный экран | OSD madVR подтвердил D3D11 fullscreen windowed. Exclusive оставался выключенным. |
| Выбор основного фильма | Baby Boom сразу открыл фильм 1:50:18; в английском плеере видны изображение и главы. |
| Смена и закрытие ISO | При смене обновлялось название; собственные подключения освобождались при смене/закрытии. |
| Начальный статичный кадр | Видно начальное уведомление Casino Royale об обновлении проигрывателя. Наблюдение ограничено этим уведомлением. |
| Обычные файлы | H.264 виден через madVR; H.264, HEVC Main10, AV1 и MPEG-2 декодированы до EOS через LAV из пакета и Null Renderer. |
| EN/RU | Обе страницы настроек Blu-ray проверены визуально. |
| BD-J | Не завершено: текущий ISO A Knight's Tale читается, но и плеер, и Windows Mount-DiskImage не подключают его с ошибкой Windows 2. Прохождение BD-J на этом ZIP не заявляется. |

Локальный вспомогательный скрипт сначала повредил окончания строк при смене
тестового INI. Это вызвало исключение на старте при чтении настроек окна
субтитров. После исправления скрипта/профиля повторный запуск и воспроизведение
основного фильма прошли; облачный архив не менялся.

Это тестовый кандидат, ещё не проверенный Release. До публикации Release нужно
завершить BD-J и оставшуюся матрицу дорожек/глав/статики/жизненного цикла на этом ZIP.
