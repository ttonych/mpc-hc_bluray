# MPC-HC Blu-ray

[English](README.md) · [Руководство пользователя](bluray/docs/USAGE.ru.md) · [История изменений](bluray/CHANGELOG.ru.md) · [Разработка](bluray/docs/DEVELOPMENT.ru.md) · [План](bluray/docs/ROADMAP.ru.md)

**Меню Blu-ray HDMV и BD-J в MPC-HC с использованием libbluray и madVR.**

Независимый экспериментальный форк для Windows x64 на основе официального
**MPC-HC 2.8.2**, с **libbluray 1.5.0** и сопровождаемыми патчами. Общие
Blu-ray-наработки берутся из [MPC-BE Blu-ray](https://github.com/ttonych/mpc-be_bluray).
MPC-HC сохраняет собственный интерфейс, граф воспроизведения и фильтры LAV
с сопровождаемым адаптером.

Целевой номер первого выпуска — **2.8.2-bluray.1**. Начало обозначает основу
MPC-HC, последнее число — выпуск форка на этой основе. См.
[нумерацию и выпуск](bluray/docs/RELEASING.ru.md). Текущие исходники показывают
версию форка в EXE/«О программе» и проверяют его опубликованные выпуски на GitHub.

## Тестовая сборка и быстрый старт

Проверенного Release пока нет. Первый облачный кандидат доступен в
[запуске Actions 35781918063](https://github.com/ttonych/mpc-hc_bluray/actions/runs/35781918063),
артефакт `mpc-hc-bluray-candidate-x64`. Может потребоваться вход в GitHub;
срок хранения артефакта — 14 дней. Точный коммит, SHA-256 ZIP и выполненные
проверки записаны в [результатах](bluray/docs/VALIDATION.ru.md).

1. Распакуйте внутренний ZIP плеера в новую папку с правом записи. Сохраните
   `mpc-hc64.ini` рядом с `mpc-hc64.exe`: он включает portable-настройки.
2. Убедитесь, что установлен Microsoft Visual C++ v14 runtime x64; см.
   [требования](bluray/docs/USAGE.ru.md#требования-и-первый-запуск).
3. Используйте внешнюю установку **madVR 210 x64** и выберите **Настройки →
   Воспроизведение → Вывод → madVR**. Основной полноэкранный режим —
   **D3D11 fullscreen windowed**. Форк не включает exclusive и не меняет
   глобальные настройки madVR.
4. Для BD-J выберите Java x64 в **Настройки → Воспроизведение → Blu-ray**.
   Проверенная версия — **Temurin 21.0.12.1+1**; для HDMV Java не нужна.
5. Выберите **Меню диска** или **Основной фильм** на этой странице. Откройте
   целый диск, `BDMV/index.bdmv` или перетащите ISO в плеер. Прямое открытие
   плейлиста или клипа воспроизводит его без полной навигации по диску.

В меню используйте стрелки и **Enter**, **Alt+T** для верхнего меню и **Alt+R**
для всплывающего. Поддержка мыши и разрешённые действия зависят от самого диска.
Отдельного пункта «Открыть меню Blu-ray» нет.

## Что добавляет форк

- Навигацию HDMV/BD-J и графику меню через madVR.
- Клавиатуру и мышь в тех меню, где она предусмотрена автором диска.
- Названия дисков, отображение глав с учётом меню/фильма, звук меню и обработку MPEG-2 статики.
- Штатное открытие Blu-ray/ISO с учётом выбора меню или основного фильма.
- EN/RU-настройки региона, языков, Java, совместимости и данных дисков.
- Каталог данных дисков со своими названиями и сбросом без удаления прежних файлов.
- Подключение ISO средствами Windows только для чтения; свои подключения освобождаются при закрытии.

Перечень описывает реализацию, а не совместимость со всеми дисками. Локальные
проверки и проверки скачиваемого ZIP разделены в
[результатах](bluray/docs/VALIDATION.ru.md).

## Профили и обновления

Держите тестовые сборки отдельно от установленных MPC-HC/MPC-BE и сохраняйте
portable-INI. Мастер импорта настроек и обязательный portable-режим из MPC-BE
Blu-ray пока не перенесены. madVR и другие внешние фильтры могут использовать
общие системные настройки в разных плеерах.

Текущие исходники проверяют опубликованные выпуски **ttonych/mpc-hc_bluray**,
включая prerelease, и предлагают открыть их страницу GitHub без установки.
Указанный выше старый облачный кандидат создан до этой правки: в нём откажитесь
от автоматической проверки. См. [профили и обновления](bluray/docs/USAGE.ru.md#профили-и-обновления).

## Текущие ограничения

- Для графики меню требуется madVR; этот путь с другими рендерерами не проверен.
- Первый облачный ZIP проверен в ограниченном объёме на HDMV, ISO, обычном файле
  и EN/RU. BD-J на нём ещё не подтверждён; локальные наблюдения его не заменяют.
- Широкая матрица дисков/Java/сохранений, положительная проверка мыши BD-J,
  полная проверка кодеков/звука, DVD ISO, точность HDR и MVC/стереовывод ещё впереди.
- Параметры совместимости сообщают возможности приложениям диска; они не
  добавляют декодеры и не доказывают поддержку всех заявленных функций.
- Java, madVR и средства расшифровки дисков не входят в комплект. Содержимое
  диска должно читаться, а ISO — подключаться штатными средствами Windows.
- Сборка LAV через MSVC использует встроенные декодеры без внешних зависимостей,
  требующих GCC.

Первые действия при ошибках и состав полезного отчёта — в
[диагностике](bluray/docs/USAGE.ru.md#диагностика-и-обратная-связь).
