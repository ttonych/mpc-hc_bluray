# MPC-HC Blu-ray

[English](README.md) · [Использование](bluray/docs/USAGE.ru.md) · [Разработка](bluray/docs/DEVELOPMENT.ru.md) · [План](bluray/docs/ROADMAP.ru.md)

Экспериментальный форк MPC-HC 2.8.2 для Windows x64 с меню HDMV/BD-J на базе
libbluray 1.5.0 и интеграцией с madVR. Выбранные общие компоненты перенесены из
[MPC-BE Blu-ray](https://github.com/ttonych/mpc-be_bluray); MPC-HC сохраняет свой
интерфейс, граф воспроизведения и сопровождаемый адаптер LAV.

Открывайте Blu-ray, папку или ISO штатными командами плеера. Страница Blu-ray
выбирает меню или основной фильм, настраивает Java, языки, регион, совместимость
и данные дисков. ISO подключаются средствами Windows; созданные плеером
подключения освобождаются при закрытии или смене диска.

madVR 210 x64 и Java устанавливаются отдельно. BD-J проверялся с Temurin
21.0.12.1+1 x64. Основной полноэкранный режим — D3D11 fullscreen windowed;
форк не включает exclusive и не меняет глобальные настройки madVR.

Это версия для разработки. Локальные результаты и пробелы записаны в
[проверках](bluray/docs/VALIDATION.ru.md). Точность HDR, стереовывод MVC и
совместимость со всеми дисками не подтверждены. Сборка LAV через MSVC использует
встроенные декодеры; внешние зависимости кодеков, требующие GCC, отсутствуют.

История официального [MPC-HC](https://github.com/clsid2/mpc-hc), авторство и
лицензии сохранены. См. [COPYING](COPYING.txt), [журнал переноса](bluray/docs/PORTING.ru.md),
[версии компонентов](bluray/sources.json) и [изменения форка](bluray/CHANGELOG.ru.md).
Полная сборка кандидата запускается вручную через Actions; выпуск подтверждается
только проверкой именно облачного ZIP с чистым portable-профилем.
